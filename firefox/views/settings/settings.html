Excluded Domains

Domains matching the rules below will not be checked against the blocklist. One rule per line.

Rule format:
  • facebook.com — excludes exactly this domain (and www.facebook.com)
  • *.example.com — excludes example.com and all subdomains (e.g. abc.example.com)

Excluded IP Addresses (WAF/Trusted)

IP addresses matching the rules below will not be flagged with an alert icon. Useful for ignoring trusted WAF providers or local subnets. One rule per line.

IP rule format:
  • 127.0.0.1 — exact IP match
  • 104.16.0.0/12 — matches the entire subnet (CIDR notation)
  • 192.168.1.* — wildcard match
